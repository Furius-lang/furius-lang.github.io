# FixPoint — сайт ремонта смартфонов

Учебный проект на HTML, CSS и JavaScript. Проект включает базовые и дополнительные задания.

## Файлы
- `index.html` — главная страница.
- `style.css` — оформление и адаптивность.
- `script.js` — интерактивные функции.
- `404.html` — страница ошибки 404.

## Дополнительные задания
1. Кнопка «Наверх».
2. Плавная прокрутка по якорям.
3. Появление карточек при прокрутке (IntersectionObserver).
4. localStorage: сохраняются язык и выбранные пункты калькулятора.
5. Страница 404.
6. Форма Netlify Forms (`data-netlify="true"`).
7. Переключение русского и английского языка.
8. Фильтр услуг по категориям и поиск по названию/описанию.
9. Слайдер без сторонних библиотек.
10. Модальное окно с подробностями карточки.

## Запуск локально
Откройте `index.html` в браузере или используйте Live Server в Visual Studio Code.

## Публикация на Netlify
1. Создайте публичный репозиторий GitHub и загрузите все файлы из этой папки.
2. В Netlify выберите Add new site → Import an existing project и подключите репозиторий.
3. Для обычного статического сайта оставьте Build command и Publish directory пустыми (или укажите `.` как папку публикации, если интерфейс просит значение).
4. После успешной публикации откройте сайт. Netlify обнаружит форму `repair-request` при сборке.
5. Отправьте тестовую заявку и проверьте раздел Forms в панели Netlify.

Важно: форма Netlify начинает принимать заявки после публикации сайта на Netlify. Адрес, телефон, цены и прочие данные в проекте демонстрационные — замените их на реальные перед сдачей.
